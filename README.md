# AplusGlobalConnect

Core React Native and Expo marketing hub for campaigns, clients, publishing, analytics, communication, and AI assistance.

## Source material

- `mainapp2/AplusGlobalConnect_project.zip`
- `Personal MindMap Notes/MAINAPP/`
- `Personal MindMap Notes/AplusGlobalConnect-Organized/01-AplusGlobalConnect/`

## Foundation order

1. Expo app and route tree
2. Firebase authentication and tenant ownership
3. Client and campaign models
4. Campaign CRUD and local emulator tests
5. One social provider end to end
6. AI and payments through server Functions only

## Current milestone

The Expo Router shell is published with local typed campaign and client data. Firebase authentication, tenant-safe rules, and server integrations are intentionally not connected yet.

## Folders

- `code/`: app, services, models, and Functions
- `docs/`: architecture and decisions
- `qa/`: emulator tests and release checks
- `config/`: environment and deployment templates
